## 1. プロジェクト概要

### 1.1 プロジェクト名
PEポータルサイト AI開発プロジェクト（Cursor自動開発）

### 1.2 目的
Cursor AIエージェントによる完全自動実装を通じて、PEポータルサイトに必要な基盤（スプレッドシート、Google Driveフォルダ、GASプロジェクト）を**自分の工数をかけずに**作成する。

### 1.3 参照プロジェクト
- **既存プロジェクト**: `work/pe_portalsite`（Google Sitesベースで進める既存の案）
- **本プロジェクト**: `work/pe_portalsite_ai_develop`（Cursor自動開発の実験プロジェクト）

### 1.4 Gitリポジトリ
- **リポジトリURL**: `https://github.com/h-watanabe-png/pe_portalsite.git`
- **ブランチ**: `ai-develop`（既存プロジェクトの`main`ブランチとは分離）
- **用途**: コードのバージョン管理、変更履歴の記録
- **注意**: 既存プロジェクト（`work/pe_portalsite`）とは別ブランチを使用し、影響を与えないようにします

## 5. 実装手順（Cursor AIエージェントへの指示）

### 5.0 自動実装の基本原則

**重要**: Cursor AIエージェントは、スプレッドシート、JSON、Markdownファイルなどの作成・編集も**完全自動で行い**、適切なGASプロジェクトに保存します。

**手動処理の削減**: 手動処理を減らすため、Cursor AIエージェントは**Pythonスクリプトを自動作成・実行**して、Google Sheets API、Google Drive API、claspなどを操作します。

#### 5.0.1 ファイル作成・編集の自動化

**対象ファイル:**
- **スプレッドシート**: Google Sheets APIを使用して作成・編集
- **JSONファイル**: GASプロジェクト内に作成・保存（clasp pushでGASに反映）
- **Markdownファイル**: GASプロジェクト内に作成・保存、またはGoogle Driveに保存
- **GASスクリプトファイル**: GASプロジェクト内に作成・保存（clasp pushでGASに反映）
- **HTMLファイル**: GASプロジェクト内に作成・保存（clasp pushでGASに反映）
- **JavaScriptファイル**: GASプロジェクト内に作成・保存（clasp pushでGASに反映）
- **CSSファイル**: GASプロジェクト内に作成・保存（clasp pushでGASに反映）

#### 5.0.2 GASプロジェクトへの保存方法

**方法1: claspを使用（推奨）**
```bash
# 1. ローカルにファイルを作成・編集
# 2. clasp pushでGASプロジェクトに反映
clasp push
```

**方法2: GAS APIを使用（claspが使えない場合）**
- GAS APIを使用して直接ファイルをアップロード
- ただし、claspの方が確実で推奨

#### 5.0.3 実装フロー（Pythonスクリプトによる自動化）

```
1. Pythonスクリプトを自動作成
   ↓
2. Pythonスクリプトを実行（Google Sheets API、Google Drive API、claspなどを操作）
   ↓
3. ファイルの作成・編集（スプレッドシート、JSON、Markdown、GASスクリプト等）
   ↓
4. ローカルに保存（work/pe_portalsite_ai_develop/配下）
   ↓
5. clasp pushでGASプロジェクトに反映
   ↓
6. Gitにコミット・プッシュ（必要に応じて）
   ↓
7. 検証（必要に応じて）
```

#### 5.0.4 Pythonスクリプトによる自動化

**目的**: 手動処理を減らすため、Cursor AIエージェントがPythonスクリプトを自動作成・実行します。

- `google-api-python-client` - Google Sheets API、Google Drive API
