### 対策4: Pythonスクリプトの安全対策

Pythonスクリプトには、**既存リソースを誤って操作しないように**以下の安全対策を実装します。

**実装例**:
```python
# 安全対策: スクリプトIDとスプレッドシートIDを明示的に指定
GAS_SCRIPT_ID = '1czGmHa0Zyz1QCS9VfTYBIpNZSIMJY2lACGtvbTv8fVHcWAekPM_fqFfT'  # 実験用
SPREADSHEET_ID = '1mivDNOXpZsE7oW7gF10Rq3NvnYjxjfiVQWp4LHIorL0'  # 実験用

# 既存プロジェクトのIDとは明確に区別
EXISTING_GAS_SCRIPT_ID = '1CZwdtE0-pWP7cUxGTJUIQctCq1DBTRac7gkhci5NddnBJsjm3T1l7qLY'  # 既存（使用しない）
EXISTING_SPREADSHEET_ID = '12jAvY-I-UMKpjT1sprYfAOxdIi8E-PqneMYjVBQ6DnY'  # 既存（使用しない）

# 誤操作防止: 既存プロジェクトのIDを使用しようとした場合はエラー
if GAS_SCRIPT_ID == EXISTING_GAS_SCRIPT_ID:
    raise ValueError("既存プロジェクトのGASスクリプトIDを使用しようとしています。実験用のIDを使用してください。")

if SPREADSHEET_ID == EXISTING_SPREADSHEET_ID:
    raise ValueError("既存プロジェクトのスプレッドシートIDを使用しようとしています。実験用のIDを使用してください。")
```
