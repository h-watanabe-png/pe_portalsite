# フォーム改善実装サマリー

## 実装日
2025-12-03

## 実装内容

### 1. Slack問い合わせ分析結果の活用

**分析結果**:
- システムチーム関連キーワード: エラー、ログイン、Filemaker、面接、選考、教師、生徒、修正など
- 経理関連キーワード: 請求、口座、クレカ、決済、振込、報酬、支払、金額など

### 2. フォーム項目の改善

#### システムチーム依頼フォーム
- **依頼種別（新規追加・必須）**: エラー対応、修正・改修、設定・セッティング、権限設定、データ修正、面接関連、選考関連、PC設定、システム不具合、その他
- **教師番号（新規追加・任意）**: 教師番号の入力欄を追加
- **推奨項目の表示**: 依頼種別を選択すると、推奨項目のヘルプテキストが表示される

#### 経理依頼フォーム
- **依頼種別（拡張・必須）**: 請求書作成、請求書修正、請求書チェック、報酬計算、報酬支払、振込手続き、クレカ決済、口座変更・登録、領収書発行、金額確認、その他
- **教師番号（新規追加・任意）**: 教師番号の入力欄を追加
- **請求月（新規追加・任意）**: 請求対象の月を選択
- **金額（新規追加・任意）**: 該当する金額を入力
- **推奨項目の表示**: 依頼種別を選択すると、推奨項目のヘルプテキストが表示される

### 3. 自動仕分け機能の実装

#### 実装ファイル
- `RequestClassifier.gs`: 自動仕分けロジックを実装
- `RequestHandler.gs`: 自動仕分け機能を統合
- `Main.gs`: 自動仕分けAPIエンドポイントを追加

#### 機能
- **キーワードベースの自動判定**: メッセージ本文からキーワードを抽出し、システムチームか経理かを自動判定
- **重み付けスコアリング**: 各キーワードに出現頻度に基づく重み付けを設定
- **信頼度の計算**: 自動仕分けの信頼度を計算（0.7以上で自動仕分け、それ以下は確認を求める）
- **依頼種別からの判定**: 依頼種別の選択により、高い重み付けで判定

### 4. 推奨項目表示機能

#### 実装内容
- 依頼種別を選択すると、推奨項目のヘルプテキストが表示される
- 推奨項目がハイライト表示される（CSSクラス `recommended` を追加）

#### 推奨項目の例
- **エラー対応**: エラーメッセージやエラー画面のスクリーンショット
- **面接・選考関連**: 選考番号、教師番号、生徒番号
- **設定関連**: 世帯ID、生徒番号
- **請求・報酬関連**: 世帯ID、請求月、金額
- **振込関連**: 世帯ID、教師番号

### 5. UI/UX改善

#### CSS追加
- `.form-group.recommended`: 推奨項目のハイライト表示用スタイル

#### フォームバリデーション
- 依頼種別を必須項目に追加
- リアルタイムバリデーションを改善

## 今後の改善案

1. **統一フォームページの作成**: システムチームと経理のフォームを統合し、自動仕分け機能を前面に出す
2. **リアルタイム自動仕分け**: 入力中にリアルタイムで自動仕分け結果を表示
3. **キーワードハイライト**: 検出されたキーワードをハイライト表示
4. **学習機能**: ユーザーの修正を学習し、自動仕分けの精度を向上
