# スプレッドシートデータ検証設定ガイド

**作成日**: 2025年12月10日  
**最終更新日**: 2025年12月10日

---

## 📋 概要

スプレッドシートにデータ検証（プルダウン）を設定することで、ユーザーが入力しなくても、プルダウンから選択して更新できるようになります。これにより、タイピングミスを防ぎ、データの整合性を保つことができます。

---

## 🎯 設定対象

### 1. 依頼_統合管理シート

以下の列にプルダウンを設定：

- **依頼元**: システムチーム、経理
- **状態**: 新規、処理中、完了、保留、キャンセル
- **優先度**: 高（業務停止）、中（業務に支障あり）、低（業務に支障なし）
- **ブランド**: EB、TKT、その他

### 2. 依頼_システムチームシート

以下の列にプルダウンを設定：

- **ステータス**: 新規、処理中、完了、保留、キャンセル
- **緊急度**: 高（業務停止）、中（業務に支障あり）、低（業務に支障なし）
- **重要度**: 高（業務停止）、中（業務に支障あり）、低（業務に支障なし）
- **ブランド**: EB、TKT、その他
- **発生頻度**: 常に発生、時々発生、初めて発生、不明

### 3. 依頼_経理シート

以下の列にプルダウンを設定：

- **ステータス**: 新規、処理中、完了、保留、キャンセル
- **緊急度**: 高（業務停止）、中（業務に支障あり）、低（業務に支障なし）
- **重要度**: 高（業務停止）、中（業務に支障あり）、低（業務に支障なし）
- **ブランド**: EB、TKT、その他
- **依頼種別**: 請求関連、支払関連、口座・決済関連、報酬関連、その他
- **締日種別**: 当月15日、翌月15日、指定日

## 🔧 設定方法

### 方法1: Pythonスクリプトで自動設定（推奨）

```bash
python scripts/setup_spreadsheet_data_validation.py
```

このスクリプトを実行すると、すべてのシートにデータ検証が自動設定されます。

### 方法2: 手動で設定

1. Googleスプレッドシート「PEポータルサイト管理」を開く
2. 設定したいシートを開く
3. 設定したい列を選択（例: 状態列）
4. 「データ」→「データの入力規則」を選択
5. 「条件」で「リスト」を選択
6. 「値」に選択肢を入力（例: 新規,処理中,完了,保留,キャンセル）
7. 「無効なデータの場合」で「警告を表示」または「入力を拒否」を選択
8. 「保存」をクリック

---

## 📊 データ検証の効果

### メリット

1. **タイピングミスの防止**: プルダウンから選択するため、入力ミスが発生しない
2. **データの整合性**: 許可された値のみを入力できるため、データの整合性が保たれる
3. **入力の高速化**: タイピングする必要がなく、選択するだけで更新できる
4. **一貫性の確保**: 同じ値が統一された形式で入力される

### 注意事項

- データ検証を設定した列は、プルダウンから選択する必要があります
- プルダウンにない値を入力しようとすると、警告または入力を拒否されます
- 新しい選択肢を追加する場合は、データ検証の設定を更新する必要があります

## 🔄 選択肢の追加・変更

### Pythonスクリプトで変更

`scripts/setup_spreadsheet_data_validation.py`の`DATA_VALIDATION_CONFIG`を編集：

```python
DATA_VALIDATION_CONFIG = {
    '依頼_統合管理': {
        '状態': ['新規', '処理中', '完了', '保留', 'キャンセル', '新規追加項目'],  # 新しい項目を追加
        # ...
    }
}
```

その後、スクリプトを再実行：

```bash
python scripts/setup_spreadsheet_data_validation.py
```

### 手動で変更

1. スプレッドシートで該当列を選択
2. 「データ」→「データの入力規則」を選択
3. 「値」のリストを編集
4. 「保存」をクリック
