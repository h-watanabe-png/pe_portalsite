## 15. IPアドレス制限機能（新規追加・ver1.0）

### 15.1 IPアドレス制御の設定確認
- [ ] スプレッドシートの「システム設定」シートに「IPアドレス制御有効」の設定がある
- [ ] スプレッドシートの「システム設定」シートに「IPアドレス許可リスト」の設定がある
- [ ] IPアドレス制御が無効（false）の場合、すべてのIPアドレスからアクセス可能
- [ ] IPアドレス制御が有効（true）の場合、許可リストに含まれるIPアドレスのみアクセス可能

### 15.2 IPアドレス取得機能
- [ ] ページ読み込み時にIPアドレスが取得される（ブラウザのコンソールで確認）
- [ ] IPアドレスがURLパラメータ（`clientIP`）として送信される
- [ ] 外部APIサービスが利用できない場合でも、エラーなく動作する（フォールバック機能）

### 15.3 IPアドレスチェック機能
- [ ] 許可リストに含まれるIPアドレスからアクセスすると、正常にページが表示される
- [ ] 許可リストに含まれていないIPアドレスからアクセスすると、「IPアドレスが許可されていません」のエラーページが表示される
- [ ] エラーページにIPアドレスが表示される（デバッグ用）

### 15.4 IPアドレス表記の確認
- [ ] 個別IPアドレス（例: `192.168.1.100`）が正しく認識される
- [ ] CIDR表記（例: `192.168.1.0/24`）が正しく認識される
- [ ] ワイルドカード表記（例: `192.168.1.*`）が正しく認識される

### 15.5 アクセスログ
- [ ] IPアドレスがアクセスログに記録される（スプレッドシートの「アクセスログ」シートを確認）
