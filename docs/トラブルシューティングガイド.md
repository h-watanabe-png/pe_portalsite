## 📋 概要

本ガイドは、PEポータルサイトで発生する可能性のある問題とその解決方法をまとめたものです。運用担当者や開発者が問題を迅速に解決できるよう、具体的な手順を記載しています。

---

## 🔧 よくある問題と解決方法

### 1. スナップショットキャッシュが更新されない

#### 症状
- ダッシュボードに古いデータが表示される
- 検索結果が最新でない
- ヘッダーのインジケーターが🟠（オレンジ）のまま

#### 原因
- キャッシュが古い（20分以上経過）
- 手動更新が実行されていない
- キャッシュ更新処理でエラーが発生

#### 解決方法

**方法1: 手動更新を実行**
1. ヘッダーの🔄ボタンをクリック
2. 更新が完了するまで待つ（⏳アイコンが表示される）
3. インジケーターが🟢（緑）になることを確認

**方法2: GASエディタから直接更新**
```javascript
// GASエディタで実行
updateSnapshotCacheManual();
```

**方法3: キャッシュを強制更新**
```javascript
// 特定のシートのキャッシュを無効化
invalidateSnapshotCache('依頼_統合管理');

// 全シートのキャッシュを無効化
invalidateSnapshotCache();

// その後、手動更新を実行
updateSnapshotCacheManual();
```

**方法4: キャッシュ状態を確認**
```javascript
// キャッシュ状態を確認
const status = getSnapshotCacheStatus();
Logger.log(JSON.stringify(status, null, 2));
```

### 2. ダッシュボードが表示されない

#### 症状
- ダッシュボードが読み込まれない
- エラーメッセージが表示される
- ローディングが終わらない

#### 原因
- 認証エラー
- スプレッドシートへのアクセス権限がない
- ネットワークエラー
- GASの実行時間制限に達した

#### 解決方法

**方法1: 認証を確認**
- Googleアカウントでログインしているか確認
- ホワイトリストに登録されているか確認

**方法2: ブラウザをリロード**
- ページをリロード（F5キー）
- ブラウザのキャッシュをクリア

**方法3: エラーログを確認**
```javascript
// GASエディタでログを確認
Logger.log('エラーログを確認');
```

**方法4: フォールバック機能を使用**
- キャッシュがない場合は、通常の方法でデータを取得
- エラー時は、エラーメッセージを表示

### 3. 依頼が送信できない

#### 症状
- フォーム送信ボタンをクリックしても送信されない
- エラーメッセージが表示される
- 送信後、依頼が表示されない

#### 原因
- 必須項目が未入力
- バリデーションエラー
- スプレッドシートへの書き込み権限がない
- ネットワークエラー

#### 解決方法

**方法1: 必須項目を確認**
- フォームの必須項目（赤い*マーク）がすべて入力されているか確認
- エラーメッセージを確認

**方法2: ブラウザのコンソールを確認**
- F12キーで開発者ツールを開く
- Consoleタブでエラーメッセージを確認

**方法3: スプレッドシートの権限を確認**
- スプレッドシートへの編集権限があるか確認
- 管理者に権限の付与を依頼

**方法4: 手動でスプレッドシートに追加**
- 一時的な対処として、スプレッドシートに直接追加
- 後でシステムに反映

---

### 4. 検索結果が表示されない

#### 症状
- 検索キーワードを入力しても結果が表示されない
- 検索結果が0件と表示される
- 検索処理が終わらない

#### 原因
- キャッシュが古い
- 検索キーワードが適切でない
- データが存在しない

#### 解決方法

**方法1: キャッシュを更新**
- ヘッダーの🔄ボタンからキャッシュを更新
- 検索を再実行

**方法2: 検索キーワードを変更**
- より具体的なキーワードで検索
- 部分一致で検索されるため、短いキーワードでも試す

**方法3: 通常の方法で検索**
- キャッシュを使用しない検索を実行
- スプレッドシートから直接検索

### 5. 締日リマインダーが送信されない

#### 症状
- 締日が近いのにリマインダーが届かない
- リマインダーが届くタイミングが遅い

#### 原因
- トリガーが設定されていない
- 締日情報が正しく設定されていない
- Slack通知の設定が正しくない

#### 解決方法

**方法1: トリガーを確認**
```javascript
// トリガー一覧を確認
const triggers = ScriptApp.getProjectTriggers();
triggers.forEach(trigger => {
  Logger.log(`トリガー: ${trigger.getHandlerFunction()}, タイプ: ${trigger.getEventType()}`);
});
```

**方法2: 手動でリマインダーを送信**
```javascript
// 手動でリマインダーを送信
sendDeadlineReminders();
```

**方法3: 締日情報を確認**
- 依頼の締日が正しく設定されているか確認
- 締日種別が正しく選択されているか確認

### 6. パフォーマンスが低下している

#### 症状
- ダッシュボードの読み込みが遅い
- 検索処理に時間がかかる
- 操作が重い

#### 原因
- データ量が増加している
- キャッシュが古い
- スプレッドシートが重い

#### 解決方法

**方法1: キャッシュを更新**
- ヘッダーの🔄ボタンからキャッシュを更新
- 最新のキャッシュを使用

**方法2: データアーカイブを実行**
```javascript
// 古いデータをアーカイブ（ドライラン）
const result = archiveOldData(true);
Logger.log(JSON.stringify(result, null, 2));

// 実際にアーカイブを実行
archiveOldData(false);
```

**方法3: スプレッドシートの最適化**
- 不要なデータを削除
- シートを分割（必要に応じて）

### 7. ロックエラーが発生する

#### 症状
- 「他のユーザーが更新中です」というエラーメッセージが表示される
- キャッシュ更新ができない

#### 原因
- 他のユーザーが同時に更新を実行している
- 前回の更新処理が正常に終了していない

#### 解決方法

**方法1: しばらく待ってから再試行**
- 数秒待ってから再度更新ボタンをクリック
- 他のユーザーの更新が完了するまで待つ

**方法2: ロックを手動で解除**
```javascript
// 更新中フラグを削除（緊急時のみ）
PropertiesService.getScriptProperties().deleteProperty('snapshot_cache_updating');
```

**方法3: ロック状態を確認**
```javascript
// ロック状態を確認
const properties = PropertiesService.getScriptProperties();
const updating = properties.getProperty('snapshot_cache_updating');
Logger.log('更新中フラグ: ' + updating);
```

## 🔍 デバッグ方法

### 1. ログの確認

**GASエディタでログを確認**
1. GASエディタを開く
2. 「実行」→「実行ログを表示」を選択
3. エラーメッセージや実行時間を確認

**ブラウザのコンソールでログを確認**
1. F12キーで開発者ツールを開く
2. Consoleタブでエラーメッセージを確認
3. NetworkタブでAPI呼び出しを確認

### 2. キャッシュ状態の確認

```javascript
// キャッシュ状態を確認
const status = getSnapshotCacheStatus();
Logger.log(JSON.stringify(status, null, 2));
```

```javascript
// スプレッドシートのデータを確認
const spreadsheetId = '1mivDNOXpZsE7oW7gF10Rq3NvnYjxjfiVQWp4LHIorL0';
const sheet = SpreadsheetApp.openById(spreadsheetId).getSheetByName('依頼_統合管理');
```

3. **スクリーンショットを撮影**: エラー画面のスクリーンショットを取得
4. **プロジェクトチームに連絡**: 上記の情報とともに連絡
