## 自動仕分け機能の実装

### 実装方針

1. **統一フォームから自動仕分け**
   - ユーザーが「依頼を送信」ボタンをクリック
   - メッセージ本文からキーワードを抽出
   - システムチーム関連キーワードと経理関連キーワードの出現頻度をカウント
   - より多く出現した方に自動仕分け
   - ユーザーに確認を求める（「システムチームへの依頼として送信しますか？」）

2. **フォーム項目から自動補完**
   - 依頼種別を選択すると、関連する項目を自動表示
   - 例: 「エラー対応」を選択 → エラーメッセージ、エラー発生画面の添付を推奨

3. **キーワードマッチングアルゴリズム**
   - 各キーワードに重み付け（出現頻度に基づく）
   - システムチームスコアと経理スコアを計算
   - スコアが高い方に自動仕分け
   - スコアが同程度の場合は、ユーザーに選択を求める

## 実装手順

1. **フォーム改善**
   - システムチーム依頼フォームに「依頼種別」を追加
   - 経理依頼フォームの「依頼種別」を拡張
   - 関連項目を追加（教師番号、請求月、金額など）

2. **自動仕分け機能の実装**
   - `RequestClassifier.gs`を作成（自動仕分けロジック）
   - フロントエンドでリアルタイム判定（入力中にキーワードを検出）
   - バックエンドで最終判定（送信前に再確認）

3. **UI改善**
   - 自動仕分け結果を表示（「システムチームへの依頼として送信しますか？」）
   - ユーザーが変更可能にする

## 期待される効果

1. **依頼の正確な仕分け**
   - キーワードベースの自動判定により、誤った依頼先への送信を防止

2. **フォーム入力の効率化**
   - 依頼種別を選択することで、必要な項目が明確になる
   - 関連情報の入力が促進される

3. **データの構造化**
   - 依頼種別が明確になることで、後続の分析やレポート作成が容易になる

4. **対応の迅速化**
   - 適切な依頼先に送信されることで、対応が迅速になる
