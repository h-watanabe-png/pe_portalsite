# 請求書締日対応設計

**作成日**: 2025年12月10日  
**最終更新日**: 2025年12月10日

---

## 📋 要件

### 基本要件
- **締日**: 毎月15日
- **目的**: ユーザーと担当者の負担を最小限にしつつ、締日に間に合うように依頼と対応ができる設計
- **対象**: 請求書関連の依頼

---

## 🎯 設計方針

### 1. 締日までの日数を自動計算
- 依頼日から締日（15日）までの日数を自動計算
- 締日が過ぎている場合は、翌月の15日を締日として設定
- 締日までの残り日数を表示

### 2. 締日アラート機能
- 締日まで7日以内: 警告表示
- 締日まで3日以内: 緊急表示
- 締日当日: 最優先表示

### 3. 自動優先度設定
- 締日までの残り日数に応じて自動的に優先度を設定
- 締日まで7日以内: 優先度「高」
- 締日まで3日以内: 優先度「最高」
- 締日当日: 緊急度「緊急」

### 4. 締日カレンダー表示
- 締日までのカウントダウン表示
- 締日までのスケジュール表示
- 過去の締日実績の表示

| deadline_alert | 締日アラート | text | - | 締日アラートレベル（自動計算） |

### 締日計算ロジック

```javascript
/**
 * 締日を計算
 * @param {Date} requestDate - 依頼日
 * @param {string} deadlineType - 締日種別（当月15日/翌月15日/指定日）
 * @param {Date} customDeadline - カスタム締日（指定日の場合）
 * @return {Object} 締日情報
 */
function calculateDeadline(requestDate, deadlineType, customDeadline) {
  const today = new Date();
  let deadline;
  
  if (deadlineType === '当月15日') {
    deadline = new Date(today.getFullYear(), today.getMonth(), 15);
    // 15日が過ぎている場合は翌月15日
    if (deadline < today) {
      deadline = new Date(today.getFullYear(), today.getMonth() + 1, 15);
    }
  } else if (deadlineType === '翌月15日') {
    deadline = new Date(today.getFullYear(), today.getMonth() + 1, 15);
  } else if (deadlineType === '指定日') {
    deadline = customDeadline || new Date(today.getFullYear(), today.getMonth() + 1, 15);
  }
  
  // 締日までの日数を計算
  const daysUntil = Math.ceil((deadline - today) / (1000 * 60 * 60 * 24));
  
  // アラートレベルを決定
  let alertLevel = 'normal';
  if (daysUntil <= 0) {
    alertLevel = 'overdue';
  } else if (daysUntil <= 3) {
    alertLevel = 'urgent';
  } else if (daysUntil <= 7) {
    alertLevel = 'warning';
  }
  
  // 優先度を自動設定
  let priority = '低';
  let urgency = '低';
  if (daysUntil <= 0) {
    priority = '高（業務停止）';
    urgency = '緊急（1時間以内）';
  } else if (daysUntil <= 3) {
    priority = '高（業務停止）';
    urgency = '緊急（1時間以内）';
  } else if (daysUntil <= 7) {
    priority = '高（業務停止）';
    urgency = '高（当日中）';
  }
  
  return {
    deadline: deadline,
    daysUntil: daysUntil,
    alertLevel: alertLevel,
    priority: priority,
    urgency: urgency
  };
}
```

## 🔔 アラート機能

### アラートレベル

| レベル | 条件 | 表示 | アクション |
|--------|------|------|-----------|
| overdue | 締日超過 | 🔴 赤 | 最優先対応 |
| urgent | 3日以内 | 🟠 オレンジ | 緊急対応 |
| warning | 7日以内 | 🟡 黄 | 注意喚起 |
| normal | 7日超 | 🟢 緑 | 通常対応 |

### アラート表示

```javascript
/**
 * 締日アラートを表示
 * @param {Object} deadlineInfo - 締日情報
 * @return {string} アラートHTML
 */
function renderDeadlineAlert(deadlineInfo) {
  const { daysUntil, alertLevel, deadline } = deadlineInfo;
  
  let alertClass = 'alert-normal';
  let alertIcon = '📅';
  let alertMessage = '';
  
  switch (alertLevel) {
    case 'overdue':
      alertClass = 'alert-overdue';
      alertIcon = '🚨';
      alertMessage = `締日を超過しています（${Math.abs(daysUntil)}日経過）`;
      break;
    case 'urgent':
      alertClass = 'alert-urgent';
      alertIcon = '⚠️';
      alertMessage = `締日まで残り${daysUntil}日（緊急）`;
      break;
    case 'warning':
      alertClass = 'alert-warning';
      alertIcon = '⚠️';
      alertMessage = `締日まで残り${daysUntil}日`;
      break;
    default:
      alertMessage = `締日まで残り${daysUntil}日`;
  }
  
  return `
    <div class="deadline-alert ${alertClass}">
      <span class="alert-icon">${alertIcon}</span>
      <span class="alert-message">${alertMessage}</span>
      <span class="alert-date">締日: ${formatDate(deadline)}</span>
    </div>
  `;
}
```

## 📅 締日カレンダー機能

### 機能概要
- 当月と翌月の締日（15日）を表示
- 締日までのカウントダウン表示
- 過去の締日実績の表示

### 実装

```javascript
/**
 * 締日カレンダーを表示
 * @return {string} カレンダーHTML
 */
function renderDeadlineCalendar() {
  const today = new Date();
  const currentMonth = today.getMonth();
  const currentYear = today.getFullYear();
  
  // 当月の15日
  const currentDeadline = new Date(currentYear, currentMonth, 15);
  const isCurrentDeadlinePassed = currentDeadline < today;
  
  // 翌月の15日
  const nextDeadline = new Date(currentYear, currentMonth + 1, 15);
  
  const activeDeadline = isCurrentDeadlinePassed ? nextDeadline : currentDeadline;
  const daysUntil = Math.ceil((activeDeadline - today) / (1000 * 60 * 60 * 24));
  
  return `
    <div class="deadline-calendar">
      <div class="calendar-header">
        <h3>請求書締日カレンダー</h3>
      </div>
      <div class="calendar-body">
        <div class="deadline-item ${isCurrentDeadlinePassed ? 'passed' : 'active'}">
          <div class="deadline-date">${formatDate(currentDeadline)}</div>
          <div class="deadline-label">${isCurrentDeadlinePassed ? '（過ぎています）' : '（当月）'}</div>
        </div>
        <div class="deadline-item ${isCurrentDeadlinePassed ? 'active' : 'upcoming'}">
          <div class="deadline-date">${formatDate(nextDeadline)}</div>
          <div class="deadline-label">${isCurrentDeadlinePassed ? '（次回締日）' : '（翌月）'}</div>
          <div class="deadline-countdown">残り${daysUntil}日</div>
        </div>
      </div>
    </div>
  `;
}
```

## 🔄 自動通知機能

### 締日リマインダー
- 締日7日前: リマインダー通知
- 締日3日前: 緊急リマインダー通知
- 締日当日: 最終リマインダー通知

### 実装

```javascript
/**
 * 締日リマインダーを送信
 */
function sendDeadlineReminders() {
  const spreadsheetId = '1mivDNOXpZsE7oW7gF10Rq3NvnYjxjfiVQWp4LHIorL0';
  const sheet = SpreadsheetApp.openById(spreadsheetId).getSheetByName('依頼_経理');
  const data = sheet.getDataRange().getValues();
  
  const today = new Date();
  today.setHours(0, 0, 0, 0);
  
  // ヘッダー行をスキップ
  for (let i = 1; i < data.length; i++) {
    const row = data[i];
    const requestType = row[9]; // 依頼内容種別
    const deadlineDate = row[10]; // 締日
    const status = row[13]; // ステータス
    
    // 請求関連で、未完了の依頼のみ
    if (requestType && requestType.includes('請求') && status !== '完了') {
      if (deadlineDate instanceof Date) {
        const deadline = new Date(deadlineDate);
        deadline.setHours(0, 0, 0, 0);
        
        const daysUntil = Math.ceil((deadline - today) / (1000 * 60 * 60 * 24));
        
        // 7日前、3日前、当日にリマインダーを送信
        if (daysUntil === 7 || daysUntil === 3 || daysUntil === 0) {
          sendDeadlineReminderNotification(row, daysUntil);
        }
      }
    }
  }
}
```
