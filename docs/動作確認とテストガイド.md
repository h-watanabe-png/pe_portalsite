## 📋 デプロイ回数について

### GASデプロイの制限

**結論**: デプロイ回数に制限はありませんが、**デプロイバージョン数に制限があります**。

- **デプロイバージョン数の制限**: 1つのスクリプトあたり**200バージョン**まで
- **デプロイ回数**: 制限なし（ただし、バージョン数が上限に達すると新しいデプロイができなくなる）
- **既存デプロイの更新**: バージョン数を消費せずに更新可能（推奨）

### 推奨される運用方法

1. **既存デプロイを更新する（推奨）**
   - 新しいバージョンを作成せず、既存のデプロイを更新
   - バージョン数を消費しない
   - デプロイURLが変わらない

2. **新しいデプロイを作成する場合**
   - テスト用と本番用を分ける場合のみ
   - バージョン数を消費するため、必要最小限に

3. **古いバージョンの削除**
   - 200バージョンに達した場合のみ削除
   - 削除しても現在のデプロイには影響しない（ロールバック不可になるだけ）

## 🧪 デプロイせずに動作確認する方法

### 方法1: GASエディタで直接実行（最も簡単）

#### 手順

1. **GASエディタを開く**
   - `https://script.google.com/d/1czGmHa0Zyz1QCS9VfTYBIpNZSIMJY2lACGtvbTv8fVHcWAekPM_fqFfT/edit`
   - または、`clasp open`コマンドで開く

2. **関数を選択して実行**
   - 上部の関数選択ドロップダウンから関数を選択
   - 例: `checkAuthorization`, `getConfig`, `searchFiles`など
   - 「実行」ボタンをクリック

3. **実行ログを確認**
   - 下部の「実行ログ」タブで結果を確認
   - `Logger.log()`の出力を確認

#### テスト用の関数を作成

```javascript
/**
 * テスト用関数（デプロイ不要）
 */
function testFunctions() {
  Logger.log('=== テスト開始 ===');

  Logger.log('2. 設定取得');
  const config = getConfig();
  Logger.log('設定: ' + JSON.stringify(config));

  Logger.log('3. ファイル検索');
```

#### 手順

1. **ローカル開発サーバーを起動**
   ```bash
   python scripts/local_dev_server.py
   ```

   - 説明に「テスト用」と記載
   - 本番用とは別のURLが生成される

2. **テスト用URLで動作確認**
   - テスト用URLで動作確認
   - 問題なければ本番用デプロイを更新

3. **テスト用デプロイの削除**
   - テスト完了後、テスト用デプロイを削除
   - バージョン数を節約

## 🧪 テストコードの作成

### 単体テストの作成

#### テスト用のファイルを作成

**`gas/Test.gs`**:

```javascript
/**
 * PEポータルサイト - テスト用関数
 * 
 * デプロイせずに動作確認するためのテスト関数
 */

/**
 * すべてのテストを実行
 */
function runAllTests() {
  Logger.log('========================================');
  Logger.log('PEポータルサイト - テスト開始');
  Logger.log('========================================');
  
  try {
    testAuthentication();
    testConfig();
    testFileSearch();
    testKnowledgeSearch();
    testDataManager();
    
    Logger.log('========================================');
    Logger.log('すべてのテストが完了しました');
    Logger.log('========================================');
  } catch (e) {
    Logger.log('テストエラー: ' + e.toString());
    Logger.log('スタックトレース: ' + e.stack);
  }
}

/**
 * 認証機能のテスト
 */
function testAuthentication() {
  Logger.log('--- 認証機能のテスト ---');
  
  try {
    const result = checkAuthorization();
    Logger.log('認証結果: ' + JSON.stringify(result));
    
    if (result.authorized) {
      Logger.log('✓ 認証成功: ' + result.userEmail);
    } else {
      Logger.log('✗ 認証失敗: ' + result.reason);
    }
  } catch (e) {
    Logger.log('✗ 認証テストエラー: ' + e.toString());
  }
}

/**
 * 設定取得のテスト
 */
function testConfig() {
  Logger.log('--- 設定取得のテスト ---');
  
  try {
    const config = getConfig();
    Logger.log('設定: ' + JSON.stringify(config));
    
    if (config && config.system) {
      Logger.log('✓ 設定取得成功');
    } else {
      Logger.log('✗ 設定取得失敗');
    }
  } catch (e) {
    Logger.log('✗ 設定取得テストエラー: ' + e.toString());
  }
}

/**
 * ファイル検索のテスト
 */
function testFileSearch() {
  Logger.log('--- ファイル検索のテスト ---');
  
  try {
    const results = searchFiles('マニュアル', '', 10);
    Logger.log('検索結果: ' + results.length + '件');
    
    if (results.length > 0) {
      Logger.log('✓ ファイル検索成功');
      Logger.log('最初の結果: ' + results[0].fileName);
    } else {
      Logger.log('⚠ 検索結果が0件（正常な場合もあります）');
    }
  } catch (e) {
    Logger.log('✗ ファイル検索テストエラー: ' + e.toString());
  }
}

/**
 * ナレッジ検索のテスト
 */
function testKnowledgeSearch() {
  Logger.log('--- ナレッジ検索のテスト ---');
  
  try {
    const result = searchKnowledge('システム', '', 10);
    Logger.log('検索結果: ' + result.total + '件');
    
    if (result.success) {
      Logger.log('✓ ナレッジ検索成功');
    } else {
      Logger.log('✗ ナレッジ検索失敗: ' + result.error);
    }
  } catch (e) {
    Logger.log('✗ ナレッジ検索テストエラー: ' + e.toString());
  }
}

/**
 * データ管理機能のテスト
 */
function testDataManager() {
  Logger.log('--- データ管理機能のテスト ---');
  
  try {
    // 問い合わせ対応履歴の追加テスト（テスト用データ）
    const testRequestId = 'TEST-' + Utilities.getUuid();
    const result = addCorrespondenceHistory(
      testRequestId,
      'テストユーザー',
      'テスト対応内容',
      'テスト結果',
      '',
      ['テスト', '動作確認']
    );
    
    if (result.success) {
      Logger.log('✓ 対応履歴追加成功: ' + result.correspondenceId);
    } else {
      Logger.log('✗ 対応履歴追加失敗: ' + result.error);
    }
  } catch (e) {
    Logger.log('✗ データ管理テストエラー: ' + e.toString());
  }
}

/**
 * パフォーマンステスト
 */
function testPerformance() {
  Logger.log('--- パフォーマンステスト ---');
  
  const startTime = new Date();
  
  // 100回の検索を実行
  for (let i = 0; i < 100; i++) {
    searchFiles('テスト', '', 10);
  }
  
  const endTime = new Date();
  const elapsed = endTime - startTime;
  
  Logger.log('100回の検索実行時間: ' + elapsed + 'ms');
  Logger.log('1回あたりの平均時間: ' + (elapsed / 100) + 'ms');
}
```

## 🚀 安全なデプロイ手順

### 1. テスト実行

```javascript
// GASエディタで実行
runAllTests();
```

### 2. テスト用デプロイの作成

1. GASエディタで「デプロイ」→「新しいデプロイ」
2. 説明に「テスト用 - YYYY-MM-DD」と記載
3. テスト用URLで動作確認

### 3. 本番用デプロイの更新

1. テストが成功したら、本番用デプロイを更新
2. 「デプロイ」→「デプロイを管理」
3. 既存のデプロイの「鉛筆アイコン」をクリック
4. 「バージョン」で「新しいバージョン」を選択
5. 「デプロイ」ボタンをクリック

### 4. 動作確認

1. 本番用URLで動作確認
2. 問題なければ完了
