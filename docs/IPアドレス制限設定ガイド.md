# IPアドレス制限設定ガイド

**作成日**: 2025年12月11日  
**最終更新日**: 2025年12月11日

---

## 📋 概要

PEポータルサイトでは、スプレッドシートでIPアドレスのホワイトリストを管理し、指定したIPアドレスのみアクセスを許可できます。

**注意**: GASでは直接IPアドレスを取得できないため、フロントエンド（JavaScript）でIPアドレスを取得し、GASに送信する方式を採用しています。

---

## 🔧 設定方法

### 1. スプレッドシートでIPアドレス制御を有効化

1. **「PEポータルサイト管理」スプレッドシートを開く**
   - スプレッドシートID: `1mivDNOXpZsE7oW7gF10Rq3NvnYjxjfiVQWp4LHIorL0`

2. **「システム設定」シートを開く**

3. **IPアドレス制御を有効化**
   - 以下の行を追加（または既存の行を更新）:
   
   | 項目名 | 値 |
   |--------|-----|
   | IPアドレス制御有効 | `true` |

   **注意**: `false` または空欄の場合は、IPアドレス制御は無効（すべてのIPアドレスを許可）になります。

### 2. IPアドレス許可リストを設定

同じ「システム設定」シートに、以下の行を追加:

| 項目名 | 値1 | 値2 | 値3 | ... |
|--------|-----|-----|-----|-----|
| IPアドレス許可リスト | `192.168.1.100` | `10.0.0.50` | `203.0.113.0/24` | ... |

**設定例**:
- **個別IPアドレス**: `192.168.1.100`, `10.0.0.50`
- **CIDR表記（IP範囲）**: `192.168.1.0/24` (192.168.1.0 ～ 192.168.1.255)
- **ワイルドカード表記**: `192.168.1.*` (192.168.1.0 ～ 192.168.1.255)

---

## 📝 IPアドレス表記方法

### 個別IPアドレス

```
192.168.1.100
10.0.0.50
203.0.113.1
```

### CIDR表記（推奨）

IPアドレスの範囲を指定できます。

```
192.168.1.0/24    # 192.168.1.0 ～ 192.168.1.255
10.0.0.0/16        # 10.0.0.0 ～ 10.0.255.255
203.0.113.0/24    # 203.0.113.0 ～ 203.0.113.255
```

**CIDR表記の説明**:
- `/24` = 最初の24ビット（3オクテット）が一致するIPアドレスを許可
- `/16` = 最初の16ビット（2オクテット）が一致するIPアドレスを許可

### ワイルドカード表記

```
192.168.1.*       # 192.168.1.0 ～ 192.168.1.255
10.0.*.*          # 10.0.0.0 ～ 10.0.255.255
```

## 🚀 動作確認

### 1. IPアドレス制御を有効化

1. スプレッドシートで「IPアドレス制御有効」を `true` に設定
2. 「IPアドレス許可リスト」に自分のIPアドレスを追加
3. ブラウザでアプリにアクセス
4. 正常にアクセスできることを確認

### 2. IPアドレス制御をテスト

1. 許可リストに含まれていないIPアドレスからアクセス
2. 「IPアドレスが許可されていません」というエラーページが表示されることを確認

## ⚠️ 注意事項

### 1. IPアドレスの取得について

- フロントエンド（JavaScript）で外部APIを使用してIPアドレスを取得しています
- 外部APIが利用できない場合、IPアドレスが取得できず、チェックがスキップされます（後方互換性のため）
- プロキシやVPNを使用している場合、実際のIPアドレスと異なる場合があります

### 2. セキュリティについて

- IPアドレス制御は**追加のセキュリティ層**として機能します
- 既存の認証・認可機能（ドメイン制限、ホワイトリスト）と併用することを推奨します
- IPアドレスは偽装可能なため、**唯一のセキュリティ手段としては使用しないでください**

### 3. 運用について

- 新しいIPアドレスを追加する場合は、スプレッドシートの「システム設定」シートを更新
- 変更は即座に反映されます（キャッシュは5分間有効）
- 誤って自分のIPアドレスを削除した場合、アクセスできなくなる可能性があります

## 🔍 トラブルシューティング

### IPアドレスが取得できない

**症状**: IPアドレスが取得できず、チェックがスキップされる

**原因**:
- 外部APIサービスが利用できない
- ネットワークエラー
- ブラウザのセキュリティ設定

**対処法**:
- ブラウザのコンソールでエラーを確認
- ネットワーク接続を確認
- 別のブラウザで試す

### 許可したIPアドレスでもアクセスできない

**症状**: 許可リストに追加したIPアドレスでもアクセス拒否される

**原因**:
- IPアドレスの表記が間違っている
- プロキシやVPNを使用している
- キャッシュが古い

**対処法**:
1. スプレッドシートの設定を確認
2. 実際のIPアドレスを確認（`https://api.ipify.org` などで確認）
3. キャッシュをクリア（5分待つか、GASのキャッシュをクリア）

### IPアドレス制御を無効化したい

**方法**:
1. スプレッドシートの「システム設定」シートを開く
2. 「IPアドレス制御有効」の値を `false` または空欄にする
3. 変更は5分以内に反映されます

## 📊 実装詳細

### フロントエンド（JavaScript）

- `index.html` の `getClientIP()` 関数でIPアドレスを取得
- 外部APIサービス（`api.ipify.org`, `api.ip.sb`, `ifconfig.me`）を使用
- URLパラメータ `clientIP` としてGASに送信

### バックエンド（GAS）

- `IPAccessControl.gs` でIPアドレスチェックを実装
- `Main.gs` の `doGet()` と `doPost()` でIPアドレスチェックを実行
- スプレッドシートの「システム設定」シートから許可リストを読み込み

### チェックロジック

1. IPアドレス制御が有効か確認
2. 許可リストを取得
3. IPアドレスが許可されているかチェック
   - 完全一致
   - CIDR表記の範囲チェック
   - ワイルドカード表記のチェック
4. 許可されていない場合はアクセス拒否
