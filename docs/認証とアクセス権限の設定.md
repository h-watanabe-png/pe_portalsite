## ⚠️ アクセス権限の設定が必要

認証ファイルは読み込めましたが、**サービスアカウントにスプレッドシートへのアクセス権限がありません**。

### エラーメッセージ
```
The caller does not have permission
```

### 解決方法

スプレッドシート「PEポータルサイト管理」の共有設定で、サービスアカウントにアクセス権限を付与してください。

#### 手順

1. **スプレッドシートを開く**
   - URL: `https://docs.google.com/spreadsheets/d/1mivDNOXpZsE7oW7gF10Rq3NvnYjxjfiVQWp4LHIorL0/edit`

2. **共有設定を開く**
   - 右上の「共有」ボタンをクリック

3. **サービスアカウントを追加**
   - 以下のメールアドレスを追加:
     ```
     md-csv-autodl@md-csv-autodl.iam.gserviceaccount.com
     ```
   - 権限: **編集者**（または**閲覧者**、必要に応じて）

4. **保存**
   - 「送信」または「完了」をクリック

5. **スクリプトを再実行**
   ```bash
   python scripts\setup_spreadsheet.py
   ```

## 🔍 確認方法

### サービスアカウントのアクセス権限を確認

スプレッドシートの共有設定で、以下のメールアドレスが追加されているか確認してください：

- `md-csv-autodl@md-csv-autodl.iam.gserviceaccount.com`

### スクリプトの実行結果を確認
