# スナップショットキャッシュ手動更新機能

**作成日**: 2025年12月10日  
**最終更新日**: 2025年12月10日

---

## 📋 概要

アプリ上でスナップショットキャッシュの最終更新時刻を表示し、古い場合は手動で更新できる機能を実装しました。複数ユーザーが同時に更新しないよう、ロック機能で制御しています。

---

## 🎯 実装内容

### 1. キャッシュ状態の表示

#### 機能
- ✅ スナップショットキャッシュの最終更新時刻を表示
- ✅ キャッシュの新旧を視覚的に表示（インジケーター）
- ✅ 古いキャッシュの場合は更新ボタンを表示

#### UI要素
- **インジケーター**: ヘッダーに表示される小さな円形インジケーター
  - 🟢 緑: キャッシュは最新（20分以内）
  - 🟠 オレンジ: キャッシュが古い（20分以上経過）
  - 🔵 青: 更新中
  - 🔴 赤: エラー
  - ⚪ グレー: 状態不明

- **更新ボタン**: キャッシュが古い場合に表示される🔄ボタン

---

### 2. 手動更新機能

#### 機能
- ✅ ワンクリックでスナップショットキャッシュを更新
- ✅ 更新中はボタンを無効化
- ✅ 更新完了後に自動で状態を再読み込み

#### ロック制御
- **LockService**を使用して同時更新を防止
- 更新中フラグをPropertiesServiceに保存
- 5分以上更新中の場合は、ロックが解除されなかったと判断して更新を続行

---

### 3. 同時更新の防止

#### 実装
```javascript
function updateSnapshotCacheManual() {
  // ロックを取得（同時更新を防止）
  const lock = LockService.getScriptLock();
  
  // ロック取得を試みる（タイムアウト: 10秒）
  if (!lock.tryLock(10000)) {
    return {
      success: false,
      error: '他のユーザーが更新中です。しばらく待ってから再試行してください。',
      locked: true
    };
  }
  
  // 更新処理...
}
```

#### 動作
1. ユーザーAが更新を開始 → ロックを取得
2. ユーザーBが更新を試みる → ロック取得失敗 → エラーメッセージを表示
3. ユーザーAの更新が完了 → ロックを解放
4. ユーザーBが再試行 → ロック取得成功 → 更新を実行

---

### 4. アプリ使用中の更新

#### 設計
- 更新処理は**非同期**で実行されるため、他のユーザーがアプリを使用していても問題ありません
- 更新中でも、既存のキャッシュデータは使用可能
- 更新完了後、次回のデータ取得時に新しいキャッシュが使用される

#### 動作フロー
1. ユーザーAがアプリを使用中
2. ユーザーBがキャッシュを更新開始
3. ユーザーAは引き続きアプリを使用可能（既存のキャッシュを使用）
4. ユーザーBの更新が完了
5. ユーザーAが次回データ取得時に新しいキャッシュを使用

---

## 🔧 使用方法

### 1. キャッシュ状態の確認

ヘッダーのインジケーターにマウスをホバーすると、最終更新時刻が表示されます。

### 2. キャッシュの手動更新

1. インジケーターが🟠（オレンジ）の場合、🔄ボタンが表示されます
2. 🔄ボタンをクリック
3. 更新中は⏳アイコンが表示されます
4. 更新完了後、自動で状態が更新されます

---

## 📊 状態表示

| 状態 | インジケーター | 説明 |
|------|---------------|------|
| 最新 | 🟢 緑 | 20分以内に更新された |
| 古い | 🟠 オレンジ | 20分以上経過している |
| 更新中 | 🔵 青 | 更新処理が実行中 |
| エラー | 🔴 赤 | 更新に失敗した |
| 不明 | ⚪ グレー | 状態を確認できない |

---

## ⚠️ 注意事項

### 1. 更新方法
- 自動更新: なし（手動更新のみの運用に変更）
- 手動更新: いつでも可能（ただし、ロック制御あり）

### 2. ロックタイムアウト
- ロック取得のタイムアウト: 10秒
- 更新処理の最大時間: 5分（それ以上はロックが解除されなかったと判断）

### 3. エラーハンドリング
- ロック取得失敗時: 「他のユーザーが更新中です」と表示
- 更新処理エラー時: エラーメッセージを表示し、インジケーターを🔴に変更
