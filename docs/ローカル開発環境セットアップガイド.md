## 📋 概要

ローカルで開発・動作確認を行い、完成したらGASに一括デプロイするための環境を構築します。

**メリット**:
- ✅ いちいち修正→デプロイ→Webで確認の繰り返しが不要
- ✅ ローカルでHTML/CSS/JavaScriptの見た目とロジックを確認可能
- ✅ 完成したら一括デプロイで効率的

**注意事項**:
- ⚠️ GASの一部機能（`google.script.run`、`Session.getActiveUser()`など）はローカルでは動作しません
- ⚠️ ローカルで確認できるのは主にHTML/CSS/JavaScriptの見た目とロジック
- ⚠️ 実際の動作確認はデプロイ後にWeb Appで行う必要があります

## 🛠️ セットアップ手順

### 1. 必要なツールのインストール

#### Node.jsとclaspのインストール

```bash
# Node.jsがインストールされているか確認
node --version

# claspをインストール
npm install -g @google/clasp

# claspのバージョン確認
clasp --version
```

#### claspログイン

```bash
cd gas

```

ブラウザが開くので、Googleアカウントでログインしてください。

## 💻 開発フロー

### ステップ1: ローカルで開発

1. **gas/フォルダ内のファイルを編集**
   - HTMLファイル: `gas/index.html`, `gas/system-team-request.html` など
   - CSSファイル: `gas/common.css`
   - JavaScriptファイル: `gas/dashboard.js`, `gas/form-handler.js` など
   - GASスクリプト: `gas/Main.gs`, `gas/Auth.gs` など

2. **ローカルで動作確認（オプション）**
   ```bash
   # ローカル開発サーバーを起動
   python scripts\local_dev_server.py
   ```
   - ブラウザで `http://localhost:8080/index.html` にアクセス
   - HTML/CSS/JavaScriptの見た目とロジックを確認
   - **注意**: `google.script.run`などのGAS関数は動作しません

### ステップ2: 完成したらデプロイ

```bash
# 一括デプロイ
python scripts\deploy_gas.py

# または強制プッシュ
python scripts\deploy_gas.py --force
```

### ステップ3: Web Appで動作確認

1. **GASエディタでWeb AppのURLを取得**
   - GASエディタを開く: `clasp open`
   - 「デプロイ」→「新しいデプロイ」を選択
   - 種類: **ウェブアプリ** を選択
   - 実行ユーザー: **自分** を選択
   - アクセスできるユーザー: **全員** または **組織内** を選択
   - 「デプロイ」をクリックしてURLを取得

2. **ブラウザでアクセスして動作確認**
   - 取得したURLにアクセス
   - 認証・認可が正常に動作するか確認
   - 各機能が正常に動作するか確認

## 📝 開発時の注意事項

### ローカルで動作しない機能

以下のGAS機能はローカルでは動作しません：

- `google.script.run` - クライアントからサーバーへの関数呼び出し
- `Session.getActiveUser()` - 現在のユーザー情報取得
- `SpreadsheetApp` - スプレッドシート操作
- `PropertiesService` - プロパティストア
- `CacheService` - キャッシュサービス
- `UrlFetchApp` - HTTPリクエスト

### ローカルで確認できること

- ✅ HTMLの構造とレイアウト
- ✅ CSSのスタイリング
- ✅ JavaScriptのロジック（GAS関数を除く）
- ✅ フォームのバリデーション
- ✅ UIの動作

### ローカルで確認できないこと

- ❌ GAS関数の実行結果
- ❌ 認証・認可の動作
- ❌ スプレッドシートへのデータ保存
- ❌ サーバー側の処理

## 🎯 推奨開発フロー

### 1. ローカル開発フェーズ

1. **HTML/CSS/JavaScriptの開発**
   - ローカル開発サーバーで見た目を確認
   - ブラウザの開発者ツールでデバッグ
   - 完成したら次のステップへ

2. **GASスクリプトの開発**
   - ローカルでは動作確認できないため、コードレビューで確認
   - デプロイ後に動作確認

### 2. デプロイフェーズ

1. **一括デプロイ**
   ```bash
   python scripts\deploy_gas.py --force
   ```

2. **動作確認**
   - Web AppのURLにアクセス
   - 各機能をテスト
   - エラーがあれば修正して再デプロイ

### 3. 継続的改善

- ローカルで開発 → デプロイ → 動作確認 → 修正 → 再デプロイ
- このサイクルを繰り返して完成度を高める

## 🔍 トラブルシューティング

### clasp pushが失敗する場合

```bash
# clasp loginを再実行
cd gas
clasp login

# 強制プッシュを試す
clasp push --force
```

### ローカル開発サーバーが起動しない場合

```bash
# ポートが使用中の場合、別のポートを使用
# local_dev_server.pyのPORT変数を変更
PORT = 8081  # 別のポート番号
```

### GAS関数が動作しない場合

- ローカルでは動作しないのが正常です
- デプロイ後にWeb Appで確認してください
