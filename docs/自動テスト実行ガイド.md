**作成日**: 2025年12月10日

## 📋 概要

本ガイドでは、**仮想環境やテスト環境を用意せず、出力結果のみで動作確認**する自動テストの実行方法を説明します。

### 特徴

- ✅ **本番データに影響なし**: 読み取り専用のテストのみ実行
- ✅ **簡単**: 1コマンドで実行可能
- ✅ **確実**: 実行ログを自動解析して問題を検出
- ✅ **安全**: テスト用の関数のみ実行し、データを変更しない

---

## 🚀 基本的な使い方

### 1. 段階的に実行（推奨）

テストを1つずつ実行し、進捗を管理します。時間がかかる場合でも、途中で中断・再開が可能です。

```bash
# 段階的に実行
python scripts/auto_test.py --staged

# 前回の続きから再開
python scripts/auto_test.py --staged --resume
```

**特徴**:
- ✅ 各テストの実行時間を表示
- ✅ 進捗バーで進捗状況を可視化
- ✅ 途中で中断しても進捗を保存
- ✅ 続きから再開可能

### 2. すべてのテストを一括実行

```bash
python scripts/auto_test.py
```

または

```bash
python scripts/auto_test.py runAllTests
```

### 3. 特定のテスト関数を実行

```bash
# 簡易テストのみ実行
python scripts/auto_test.py quickTest

# パフォーマンステストのみ実行
python scripts/auto_test.py testPerformance

# 段階的実行で特定のテストのみ
python scripts/auto_test.py --staged quickTest
```

### 4. 進捗の管理

```bash
# 保存された進捗をクリア
python scripts/auto_test.py --clear-progress
```

```

```

## 🔍 テスト内容

### 実行されるテスト

`runAllTests()` を実行すると、以下のテストが実行されます：

1. **認証機能のテスト** (`testAuthentication`)
   - 認証・認可機能が正常に動作するか確認

2. **設定取得のテスト** (`testConfig`)
   - 設定ファイルが正常に読み込めるか確認

3. **ファイル検索のテスト** (`testFileSearch`)
   - ファイル検索機能が正常に動作するか確認

4. **ナレッジ検索のテスト** (`testKnowledgeSearch`)
   - ナレッジベース検索が正常に動作するか確認

5. **データ管理機能のテスト** (`testDataManager`)
   - データ追加機能が正常に動作するか確認

### テストの安全性

- **読み取り専用**: データを変更するテストは実行されません
- **テスト用データ**: テスト用のデータのみ使用（`TEST-`プレフィックス付き）
- **本番データに影響なし**: 実際のデータは一切変更されません

## 🛠️ トラブルシューティング

### claspがインストールされていない

**エラー**:
```
✗ エラー: claspがインストールされていません
```

**解決方法**:
```bash
npm install -g @google/clasp
```

### .clasp.jsonが見つからない

**エラー**:
```
✗ エラー: .clasp.jsonが見つかりません
```

**解決方法**:
1. `gas/.clasp.json` が存在するか確認
2. 存在しない場合は、`scripts/setup_gas_project.py` を実行

### claspにログインしていない

**エラー**:
```
実行エラー: ...
```

**解決方法**:
```bash
cd gas
clasp login
```

### ログが取得できない

**エラー**:
```
⚠ 警告: ログが取得できませんでした
```

**解決方法**:
1. GASエディタで直接確認: `clasp open`
2. 実行ログタブで確認
3. 数秒待ってから再実行

## 📝 テスト関数の追加

新しいテスト関数を追加する場合は、`gas/Test.gs` に追加してください。

```javascript
/**
 * 新しいテスト関数
 */
function testNewFeature(results) {
  Logger.log('--- 新機能のテスト ---');
  
  try {
    // テスト処理
    const result = newFeatureFunction();
    
    if (result && result.success) {
      Logger.log('✓ 新機能テスト成功');
      results.passed++;
    } else {
      Logger.log('✗ 新機能テスト失敗');
      results.failed++;
      results.errors.push('新機能テスト失敗: ' + (result.error || '不明'));
    }
  } catch (e) {
    Logger.log('✗ 新機能テストエラー: ' + e.toString());
    results.failed++;
    results.errors.push('新機能テストエラー: ' + e.toString());
  }
}
```

そして、`runAllTests()` に追加：

```javascript
function runAllTests() {
  // ...
  testNewFeature(results);
  // ...
}
```

## 🔄 CI/CDへの統合

### GitHub Actionsでの実行例

```yaml
name: Auto Test

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      
      - name: Setup Node.js
        uses: actions/setup-node@v2
        with:
          node-version: '16'
      
      - name: Install clasp
        run: npm install -g @google/clasp
      
      - name: Setup clasp
        run: |
          cd gas
          clasp login --creds ${{ secrets.CLASP_CREDENTIALS }}
      
      - name: Run tests
        run: python scripts/auto_test.py
```
