## 📋 修正内容

### 1. **`Main.gs` - `const path`の再代入エラー**

**問題**: 
- 156行目で`const path`として宣言
- 164行目で`path = 'index'`として再代入しようとしている

**修正**:
```javascript
// 修正前
const path = e.parameter.path || 'index';
// ...
path = 'index'; // エラー: constは再代入不可

// 修正後
let path = e.parameter.path || 'index';
// ...
path = 'index'; // OK
```

**ファイル**: `gas/Main.gs` (156行目)

---

### 2. **`RequestHandler.gs` - `requestData`変数名エラー**

**問題**:
- `saveRequest`関数内で`requestData`を使用しているが、パラメータ名は`data`
- 271行目で`requestData.autoClassified`を参照しているが、`requestData`は未定義

**修正**:
```javascript
// 修正前
function saveRequest(data, requestType, userEmail) {
  // ...
  if (requestData.autoClassified && requestData.classificationResult) {
    // requestDataは未定義
  }
  return response; // responseオブジェクトを返しているが、関数の戻り値型はstring
}

// 修正後
function saveRequest(data, requestType, userEmail) {
  // ...
  if (data.autoClassified && data.classificationResult) {
    // dataを使用
  }
  return requestId; // requestIdを返す（関数の目的に合わせて）
}
```

**ファイル**: `gas/RequestHandler.gs` (271行目)

---

### 3. **`SlackIntegration.gs` - `threadUrl`スコープエラー**

**問題**:
- `if`ブロック内で`const threadUrl`として定義
- `return`文で`threadUrl`を使用しているが、スコープ外の可能性

**修正**:
```javascript
// 修正前
if (response.getResponseCode() === 200) {
  const responseData = JSON.parse(response.getContentText());
  if (data.requestId && responseData.ts) {
    const threadUrl = `https://...`; // ifブロック内で定義
    saveSlackThreadInfo(...);
  }
  return {
    threadUrl: threadUrl // スコープ外の可能性
  };
}

// 修正後
if (response.getResponseCode() === 200) {
  const responseData = JSON.parse(response.getContentText());
  let threadUrl = ''; // 関数スコープで定義
  if (data.requestId && responseData.ts) {
    threadUrl = `https://...`; // 値を代入
    saveSlackThreadInfo(...);
  }
  return {
    threadUrl: threadUrl // OK
  };
}
```

**ファイル**: `gas/SlackIntegration.gs` (44-58行目)
